# Review Sentiment Analysis

This project performs sentiment analysis on the **Amazon Reviews** dataset (sourced from Kaggle) using a custom pipeline for text preprocessing and sentiment scoring.

## Features
- **Dataset**: Amazon Reviews from Kaggle.
- **Text Preprocessing**: Cleaning, tokenization, stemming, and stopword removal using standard **NLTK libraries**.
- **Visualization**: Sentiment distributions and insights using **matplotlib**.

## Next Steps
Refine preprocessing to handle context-specific cases like negations, slang, and intensifiers. Enhance the lexicon with domain-specific words and explore a hybrid approach combining machine learning features for improved accuracy.
